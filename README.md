# 预设分组（TauriTavern / SillyTavern）

v0.2.3 交互、主题与分类识别优化版。仅管理 Chat Completion 预设。

- 扩展设置沿用酒馆原生 `inline-drawer` 结构；内容仅提供「显示悬浮球」和「打开预设分组」。
- 左下角扩展魔法棒菜单提供「预设分组」快捷入口。
- 可选显示「预」字悬浮球，支持拖动后自动吸附最近的左右边缘、侧边半隐藏和位置记忆；点击半隐藏悬浮球一次即可展开并打开面板，关闭面板 1 秒后自动收回。
- 独立面板提供跟随酒馆、固定暖米白日间、固定灰色夜间三种主题。只有跟随模式读取酒馆主题；固定主题不受酒馆配色影响，输入框和弹窗控件使用独立底色。
- 独立面板「全部」和「分类」页的分组首次升级后默认全部折叠；展开的分组在 30 秒无操作后自动全部收起。原生预设入口不启用自动折叠。
- 「全部」页工具栏提供小尺寸「全部展开」和「全部收起」按钮。
- 原生预设选择器保持原样；快捷分组九宫格每页最多 9 个分组，分页位于九宫格下方、筛选结果上方；翻页不清除已选分组。
- 面板支持分组排序及分组内部预设排序；点击「排序」后直接拖动左侧把手调整，无长按等待和额外插入线，排序时禁用预设切换。
- 新导入的预设置顶并显示「新」，不改变已有条目之间的相对顺序。
- 分类识别先剥离明确版本标记（如 `V1.23`、`v1.2`、`版本2.0`）；未标记的末尾数字保留原样，并额外尝试剥离一个候选版本后缀。比较时不会同时剥离两边的未标记数字。
- 名称相似度以最长连续相同字符数除以较长名称长度计算，至少要求 2 个连续相同字符。40% 起进入候选；80% 以上且候选唯一、未依赖模糊数字剥离时才自动归组；其余进入「待确认」。
- 分类页提供「重新识别自动分类」。重识别保留手动分组、手动归属、已确认合并、收藏、分组顺序及分组内排序。
- 算法版本升级时自动重新计算自动分类一次；用户手动操作的数据不会被覆盖。
- 搜索、标签和列表滚动尽量保持原位；不替换原生选择框、不重写原生事件，以减少与「预设工坊」等扩展的冲突。
- 收藏、分组、排序和主题数据独立保存在扩展设置中，不修改原始预设 JSON。

仍需在 TT 安卓/iOS 与「预设工坊」共存环境实机验证。
