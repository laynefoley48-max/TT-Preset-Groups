# 预设分组（TauriTavern / SillyTavern）

v0.2.14 九宫格单选与多选开关版。仅管理 Chat Completion 预设。

## 入口与切换

- 分组入口放在原生预设名称及保存、编辑、新建按钮的完整操作行下方，不再将原生按钮挤到下一行；不修改原生控件。
- 扩展栏新增「打开位置」下拉选项：悬浮球 / 魔法棒 / 悬浮球 + 魔法棒。选择悬浮球则隐藏魔法棒内的预设分组入口；选择魔法棒则隐藏悬浮球；选择两者则都可打开面板。默认两者同时显示。
- 旧版使用过「显示悬浮球」开关的用户会继承原设置：原先关闭对应「魔法棒」，原先开启对应「悬浮球 + 魔法棒」。
- 独立面板底部仅显示未保存修改检查和版本号，左右排列在同一行。
- 原生预设入口保留「点击悬浮按钮进行分组」，第二句改为「点击分组查看预设，点击预设可切换。」。
- 扩展栏沿用酒馆原生 `inline-drawer` 结构；提供「打开位置」下拉框和「打开预设分组」按钮。
- 左下角扩展魔法棒菜单提供「预设分组」快捷入口。
- 悬浮球默认开启；支持拖动、左右边缘吸附、侧边半隐藏、位置记忆；点击半隐藏悬浮球一次即可展开并打开面板，关闭面板 1 秒后自动收回。用户手动关闭后会记住选择。
- 独立面板标题提示「点击预设即可安全切换」；点击预设名称即可切换。
- 修复部分安卓 ST 在独立窗口打开后上半部分被屏幕裁切的问题：窗口随实际可见屏幕居中，系统键盘弹出及屏幕尺寸变化时自动调整；底部和顶部都可正常触达。
- 切换前可检查当前预设是否存在未保存修改，并选择保存后切换、不保存直接切换或取消。

## 面板功能

- 「全部」：查看所有预设，按分组归类，支持搜索、展开/收起和排序；每个分组标题右侧提供铅笔按钮，可单独修改显示名称。
- 「收藏」：集中显示已收藏的预设。
- 「分类」：自动识别系列，也可手动创建分组、添加预设；一个预设可以同时属于多个分组。
- 分类中的不确定匹配会进入「待确认合并」，由用户确认合并或排除。
- 修改分组显示名称不会修改自动识别所使用的原始匹配锚点；手动分组的成员关系也保持不变。即使把用于匹配的原始预设本身改名，也不会改变该系列已有的历史匹配锚点。
- 预设条目右侧提供铅笔按钮，可重命名非当前预设而不切换当前预设；当前正在使用的预设使用 TT 原生重命名接口，并保留当前配置。若改名失败，会避免移动其他预设的索引，尽量保留原始内容。
- 「全部」和「分类」页面均默认折叠，提供「排序」「全部展开」「全部收起」操作；展开后 30 秒无操作自动收起。该定时器仅在需要时运行，不增加自动折叠轮询。
- 在分组编辑器中勾选成员时只暂存选择，点击「完成」后一次性保存和刷新；从 A 组编辑预设并移至 B 组后，留在 A 组，不自动展开 B 组。从未分组的入口编辑时仍可定位新增的目标分组。如果没有实际改动，则关闭编辑框而不刷新。
- 修复点击分组标题时展开/收起状态存储相反、导致重命名或刷新后分组异常展开的问题。升级后仅重置一次旧的错误折叠状态为默认折叠，不影响归属及排序。
- 从 A 组编辑成员时，添加或移走预设后保持 A 组展开并定位到 A；若 A 已空，在「全部」中临时保留空分组，离开当前页面后恢复隐藏空组的规则。
- 滚动恢复同时记录可见的分组卡片与内部预设条目；当原列表因成员移动而缩短或消失时，会依次寻找仍存在的锚点，避免滚动位置突然上移。
- 点击面板右上角「说明」可查看功能介绍与亮点；说明按钮紧邻调色盘。
- 固定日间模式使用中性灰白配色，固定夜间模式使用灰色配色；只有「跟随酒馆」模式读取酒馆主题。
- 原生预设入口标题旁保留两句提示：「点击悬浮按钮进行分组」「点击分组查看预设，点击预设可切换。」

## 排序

- 点击「排序」进入排序模式，直接拖动左侧把手，无长按等待。
- 分组和分组内部预设均可排序；拖动时在目标条目边缘显示插入位置。
- 分类页中，手动分组与自动识别系列分别排序；不跨类别拖动。
- 排序模式下禁用预设名称切换，避免误触；点击「完成」退出。

## 原生入口

- 不替换或隐藏原生预设选择器，不重写其 change 事件。
- 快捷分组九宫格每页最多 9 个分组；九宫格下方的紧凑一行左侧加入「□ 多选」复选框，右侧保留分页按钮；即使只有一页也显示复选框；翻页不清除已选分组。
- 默认单选分组：点新分组替换此前筛选，再点当前分组可清除；勾选「多选」后才可跨分组累加选择，结果取并集且同一预设只显示一次；取消勾选时若已选择多个分组，则仅保留最近选中的一个。多选开关每次载入默认为关闭；升级时曾保存的多个筛选只保留最后一个。原生预设列表仍保留原有「全部」入口。
- 原生预设入口不启用 30 秒自动折叠；标题右侧保留「未筛选」或已选数量，说明文字与标题同行，不增加独立说明行。

## 分类识别与数据

- 明确版本标记（如 `V1.23`、`v1.2`、`版本2.0`）会从名称比较中剥离；未标记的末尾数字保留原样，并额外尝试剥离一个候选后缀。比较时不会同时剥离两边的未标记数字。
- 名称相似度以最长连续相同字符数除以较长名称长度计算，至少要求 2 个连续相同字符。40% 起进入候选；80% 以上且候选唯一、未依赖模糊数字剥离时才自动归组。
- 分类页提供「重新识别自动分类」。重识别保留手动分组、手动归属、已确认合并、收藏、分组顺序及分组内排序。
- 收藏、分组、排序、主题和折叠状态独立保存在扩展设置中，不修改原始预设 JSON。
- 更新时保留既有分组、收藏、排序及手动分类数据；默认悬浮球会对旧版默认关闭状态迁移一次，之后以用户手动开关为准。

仍需在 TT 安卓/iOS 与「预设工坊」共存环境实机验证。
