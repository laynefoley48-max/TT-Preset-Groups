# 预设分组（TauriTavern / SillyTavern）

v0.2.0 交互与视觉优化版。仅管理 Chat Completion 预设。

- 扩展设置使用酒馆原生 `inline-drawer` 结构；标题栏不设置自定义宽度、高度、内边距或边框，沿用原生样式。内容仅提供「显示悬浮球」和「打开预设分组」。
- 左下角扩展魔法棒菜单增加「预设分组」快捷入口。
- 可选显示「预」字悬浮球，支持拖动定位，位置保存在扩展设置中。
- 独立面板提供跟随酒馆、日间、灰色夜间三种主题；主题入口位于面板标题栏，不占用原生预设选择区域。
- 原生预设选择器保持原样，下方分组多选筛选结果滚动区域缩短为约四条预设高度；不额外增加「全部」分组按钮。
- 面板支持分组排序及分组内部预设排序；必须先开启排序模式，再在独立把手上长按约 2 秒进入拖动，排序时禁用预设切换。
- 新导入的预设置顶并显示「新」，不改变已有条目之间的相对顺序。
- 自动识别明确版本号；名称相似度 50%–84% 的候选进入「待确认匹配」，高可信度结果自动归组。可手动纠错。
- 搜索、标签和列表滚动尽量保持原位；不替换原生选择框、不重写原生事件，以减少与预设工坊等扩展的冲突。
- 收藏、分组、排序和主题数据独立保存在扩展设置中，不修改原始预设 JSON。

仍需在 TT 安卓/iOS 与「预设工坊」共存环境实机验证。
