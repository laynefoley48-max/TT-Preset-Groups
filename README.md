# 预设分组（TT / SillyTavern）

**v0.1.0 · 试用版 · 前端扩展**

专门管理 **Chat Completion** 预设：自动识别同系列、手动分类、收藏和快速切换；不会修改/删除预设 JSON 的内容。

## 使用

1. 作为普通 SillyTavern / TauriTavern 前端扩展安装（将本文件夹的源码放到独立 GitHub 仓库后，可以通过 TT 的「安装扩展」粘贴仓库链接）。
2. 打开 Chat Completion 的 API 连接面板，在原生预设选择器下方找到「预设分组」。默认收起；展开后可以多选分组，取并集筛选预设。选中的分组在下次打开时保留。取消全部分组时显示所有预设。
3. 扩展栏的「预设分组」可打开独立管理窗口。顶部「全部 / 收藏 / 分类」，每个预设可收藏、管理其所属分组；一个预设可属于多个分组。
4. 点击预设名称切换。如果检测到未保存的预设修改，将出现「保存并切换 / 不保存并切换 / 取消切换」。

## 规则

- 自动归类：去掉名字末尾清晰的 `v1.2.3` 一类版本号，再用最长连续相同片段 / 较长名称长度估算相似度，至少 50% 且至少连续 2 字符；多个分组匹配相近时保持独立。不使用 AI，也不扫描正文。
- 手动优先：手工加入或移出分组会持久保存；已处理过的预设不因重新扫描而被强制归类。
- 分组默认按中文拼音及英文名称自然排序；同系列有标准版本号时优先版本号降序。
- 无分组的预设在「未分类 / 独立预设」中显示。
- 分组是多对多关系，收藏与分组相互独立。
- 原生筛选通过一个与原生选择器同步的筛选选择框完成：没有筛选时继续显示原生选择框，有筛选时显示同步框；原生选项始终保留，不会移除。
- 默认非全屏弹窗，内层滚动，颜色跟随 ST 主题。仅保存分组信息至 extensionSettings。

## 重要：v0.1.0 的测试范围

- 主要面向 **Chat Completion** 预设；尚未覆盖 Text Completion、Instruct/Context 模板。
- 未保存检查使用原生 `getChatCompletionPreset()` 快照与已加载版本的可比字段进行保守比较。并非所有第三方魔改字段都能识别；若无法可靠判断，插件会提示而不是假定无修改。**切换前仍建议备份重要预设。**
- 原生用户选择器的未保存检测通过捕获原生 change 事件完成；被其他扩展直接调用的程序化切换不能保证拦截。
- GitHub 自动更新未启用；完成 TT 实机测试后再考虑发布正式版。
- 这是可安装测试的代码，尚未在你的 TT 安卓 / iOS 真机环境实测。

## 文件

- `manifest.json`：扩展元数据
- `index.js`：分组算法、原生筛选适配、弹窗、切换逻辑
- `style.css`：布局与跟随主题的样式

## 安全

分组、收藏、删除分组不删除或改写原始预设。只有在确认框点击「保存并切换」时，才尝试通过 TT 原生预设保存接口覆盖当前**同名预设**，成功后执行切换。
