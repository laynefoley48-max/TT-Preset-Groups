# 预设分组（TauriTavern / SillyTavern）

v0.1.1 兼容性修复试用版。仅管理 Chat Completion 预设。

- 原生预设选择框不隐藏、不复制、不修改选项和事件，尽量兼容其他预设扩展。
- 原生选择器下方保留「预设分组」三列多选筛选，展开时会出现筛选结果按钮，点击名字调用原生管理接口切换。原生下拉列表本身始终保留完整预设。
- 独立面板「全部」按系列折叠；左侧 ⠿ 按住拖动分组排序，顺序同步到原生多选九宫格。
- 「分类」页面区分「我的分组」与「自动识别的系列」；创建新分组后立即打开预设勾选器；已有分组可点击「＋ 选择预设」批量添加或移出。
- 同一预设可属于多个分组。收藏、分组信息单独保存在扩展设置中，不修改原预设。
- 从独立面板或筛选结果按钮发起切换时支持未保存提醒。为兼容其他扩展，不再拦截原生下拉框或第三方插件发起的切换，因此这两类切换不保证弹出保存提醒。

这是未经过 TT 安卓/iOS 与「预设工坊」双插件实机验证的测试版；请先使用测试预设验证切换与保存提醒。
